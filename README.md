## 📖 О проекте

Этот проект представляет собой интерактивную Wiki по игре **LonaRPG** — мрачной survival RPG с открытым миром, созданной разработчиком Eccma417.

Wiki содержит полную информацию об игре:
- 🎯 **Советы для начинающих** — как выжить в первых часах игры
- 📜 **Все квесты** — подробное описание каждого квеста с наградами и советами
- ⚔️ **Билды персонажа** — Воин, Маг, Суккуб и другие стили игры
- 🛡️ **Оружие и броня** — полные таблицы всех предметов
- 👥 **Персонажи** — все NPC, компаньоны и враги
- 🎬 **Концовки** — все варианты финала игры
- ⚙️ **Механики** — боевая система, заработок, рабство, сложность
- 🔮 **Секреты** — пасхалки, скрытые области, эксплойты

## 🎮 Об игре LonaRPG

**LonaRPG** — это open-world survival RPG, где вы играете за Лону, девушку-беженку, пытающуюся покинуть остров Ноэр.

### Основные особенности:
- 🌍 Открытый мир с множеством локаций
- ⚔️ Пошаговая боевая система на сетке
- 📊 Глубокая система характеристик и навыков
- 🏘️ Множество городов и поселений
- 📋 Десятки квестов (сюжетных и повторяющихся)
- 🎭 Разветвлённые концовки
- ⛓️ Уникальная механика рабства
- 🔄 Система перерождения (NG+)

### Главная цель:
Собрать **20-30 золотых монет** (зависит от сложности) и купить билет на корабль у капитана Эдварда.

### Локальная разработка

```bash
# Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/lonarpg-wiki.git

# Перейти в директорию
cd lonarpg-wiki

# Установить зависимости
npm install

# Запустить dev сервер
npm run dev

# Собрать production версию
npm run build
```

- **Easy/Normal** — стандартная игра (20 золотых)
