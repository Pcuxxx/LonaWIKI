# LonaRPG: Архив Ноэра

Русскоязычный путеводитель по **LonaRPG** — survival RPG от Eccma417, где беженка Лона пытается собрать 20–30 золотых монет и уплыть с острова Ноэр.

Сайт: **https://pcuxxx.github.io/LonaWIKI/**

## Что внутри

- **53 квеста** — сюжет, побочные линии, повторяемые заказы и истории компаньонов: шаги, требования, награды, советы и пропускаемые сцены.
- **10 билдов** — от HQ-бойца и мечника со щитом до стелс-ассасина, лучника, трёх магов, суккуба и ловчего. Статы, черты, снаряжение, ротации, честные минусы.
- **Снаряжение** — оружие, броня, одежда, аксессуары и 9 сетов. Цены в TP, требования, вырезанные предметы помечены.
- **Предметы** — еда, медицина, материалы, услуги и квестовые вещи.
- **18 персонажей и компаньонов** — кто помогает, кого можно забрать на корабль, как вербовать.
- **Бестиарий** — враги и боссы, их слабости, атаки и дроп.
- **45 локаций** — координаты, опасность, точки интереса, лут и советы. Отдельно — 17 служебных карт разработчика, помеченных как отладка и тесты.
- **Карта** — настоящая география игры с детальными тайлами, метками, кластерами и поиском до 16×.
- **Инструменты** — котёл, сравнение снаряжения, список покупок и сборка комплекта с весом и требованиями.
- **Трекер и сообщество** — прогресс в браузере с экспортом/импортом, форма правок, комментарии на странице, обсуждения и открытые JSON-выгрузки.
- **Статистика** — приватный журнал этого браузера: просмотры, поиск, карта и инструменты. Без cookie, регистрации и отправки персональных данных.
- **74 достижения** — с пометками о пропускаемых.
- **7 концовок** — от побега до ядерной погибели; условия спрятаны за спойлерами.
- **Механики** — управление, статы, бой, стелс, выживание, экономика, Rebirth, сложность и взрослые системы (18+).
- **Секреты** — скрытые комнаты, картины, пасхалки и вырезанный контент со статусами.
- **Источники и версии** — что проверено и где возможны расхождения.

## Стек

- React 18 + TypeScript
- Vite 6
- Tailwind CSS 4
- History API с чистыми URL и поддержкой старых hash-ссылок
- Lucide Icons

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run typecheck
npm run build
npm run validate   # проверка dist: JSON, страницы, sitemap
```

## Комментарии

Основной режим — **Supabase**: анонимные комментарии прямо на странице, без регистрации и GitHub. Нужны две публичные переменные сборки: `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`. Anon key публичен по своей природе — доступ ограничен RLS-политиками.

Настройка проекта (около пяти минут):

1. Создайте бесплатный проект на [supabase.com](https://supabase.com/dashboard).
2. Откройте **SQL Editor** и выполните [`supabase/schema.sql`](supabase/schema.sql) целиком.
3. В **Project Settings → API** скопируйте `Project URL` и `anon public` key.
4. Добавьте их в **Settings → Secrets and variables → Actions → Variables** репозитория как `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY` (или в `.env.local` для локальной сборки).

Схема включает: имя без регистрации, ответы одного уровня, удаление своих записей по токену браузера, ограничение частоты и колоночные права (чужой `client_id` прочитать нельзя). Модерация — колонка `hidden` в таблице `comments`; скрытые записи не выдаются API.

Без ключей работает резервный режим: [Giscus](https://giscus.app), если на репозиторий установлено приложение giscus, иначе GitHub Issues. В резервном режиме публикация открывает компактное окно GitHub, а в тело попадает только авторский текст; маркер страницы спрятан в HTML-комментарии.

## Деплой

Push в `main` запускает GitHub Actions. `vite.config.js` автоматически выставляет `base: "/LonaWIKI/"` при сборке в GitHub Actions; локально используется корень.
